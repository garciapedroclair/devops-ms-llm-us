# LLM for User Stories Replicate Package

This project is a analitical dashboard implemented as a microservice architecture:

- **Backend**: FastAPI  
- **Frontend**: React
- **Database**: PostgreSQL  
---

## Prerequisites
- Docker & Docker Compose installed
- node -v -> v20.19.6
- npm -v -> 10.8.2
- docker --version -> Docker version 28.3.2, build 578ccf6
- docker-compose --version -> Docker Compose version v2.40.3-desktop.1
---

## Clone the repository

- Install Sever
- Install Client
